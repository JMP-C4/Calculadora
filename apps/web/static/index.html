Para makers

Tu EDO, también por API.

El servidor no necesita frameworks externos. Levanta el proceso y usa los mismos endpoints que alimentan este lienzo.

POST/solveresolver + verificar
POST/plotdatos de las 7 gráficas
GET/healthestado del servidor

Documentación completa en README.md. La interfaz de escritorio usa el mismo motor y conserva los atajos de siempre.

terminal 
# resolver y verificar una EDO
curl -s http://127.0.0.1:8000/solve \
  -H 'Content-Type: application/json' \
  -d '{"equation": "y'"'"' = x + y", "x0": 0, "y0": 1}'

# obtener los datos de una gráfica
curl -s http://127.0.0.1:8000/plot \
  -H 'Content-Type: application/json' \
  -d '{"equation": "y'"'"' = x + y", "mode": "direction_field"}'

# abrir el workspace
python -m apps.web.server --port 8000
